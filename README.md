# expense-tracker-dashboard

A responsive expense tracker dashboard built with HTML, CSS and JavaScript.

## Features

- Add income and expense transactions
- Delete transactions
- Search transactions
- Filter by category
- Sort by newest, oldest, highest and lowest amount
- Total balance, income and expense summaries
- Spending breakdown chart bars
- LocalStorage persistence
- Dark/light mode
- Responsive dashboard layout

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub Pages
